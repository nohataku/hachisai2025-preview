# 八王子祭ホームページ お知らせ管理システム 完全ガイド

## 📖 このドキュメントについて

このドキュメントは、第63回八王子祭ホームページのお知らせ機能を管理するためのシステム説明書です。運営メンバーの誰でも、このガイドを読むことでお知らせの追加・更新ができるようになります。

**最終更新日**: 2025年7月8日

---

## 🎯 システム概要

八王子祭ホームページでは、お知らせを効率的に管理するため、**JSON（JavaScript Object Notation）**ベースの高度な自動更新システムを導入しています。

### 主な特徴

- ✅ **指定日時での自動公開** - 年月日だけでなく時刻まで指定可能
- ✅ **アクセス制御** - 公開前のお知らせへの直接アクセスを防止
- ✅ **1つのファイル更新で全ページに反映**
- ✅ **自動で日付順ソート**
- ✅ **エラー時の適切な表示**

## 🚀 新しいお知らせを追加する方法

### notices.json 直接編集（推奨）

#### STEP 1: notices.json を開く

`Notice/notices.json` をテキストエディタで開きます。

#### STEP 2: 新しいお知らせデータを追加

配列の**先頭**に新しいお知らせを追加してください。

| 項目 | 入力例 | 説明 |
|------|--------|------|
| **id** | `notice-4` | 一意の識別子（連番推奨） |
| **datetime** | `2025-08-15T10:00:00` | 公開日時（YYYY-MM-DDTHH:MM:SS形式） |
| **title** | `新企画の詳細を公開しました` | お知らせのタイトル |
| **summary** | `第63回八王子祭の新企画詳細情報を公開いたしました。` | 概要文（1-2行程度） |
| **file** | `Notice-4.html` | 個別ページファイル名 |

#### 📅 datetime 形式について

公開日時は `YYYY-MM-DDTHH:MM:SS` の形式で指定します：

- `2025-08-15T09:00:00` → 2025年8月15日 午前9時に公開
- `2025-12-01T14:30:00` → 2025年12月1日 午後2時30分に公開
- `2025-07-10T00:00:00` → 2025年7月10日 午前0時（深夜）に公開

**更新前:**

```json
{
  "notices": [
    {
      "id": "notice-3",
      "datetime": "2025-08-01T09:00:00",
      "title": "お笑いライブ出演芸人の情報を公開いたしました",
      "summary": "第63回八王子祭のお笑いライブに出演いただく芸人の情報を公開いたしました。",
      "file": "Notice-3.html"
    }
  ]
}
```

**更新後:**

```json
{
  "notices": [
    {
      "id": "notice-4",
      "datetime": "2025-08-15T10:00:00",
      "title": "新企画の詳細を公開しました",
      "summary": "第63回八王子祭の新企画詳細情報を公開いたしました。",
      "file": "Notice-4.html"
    },
    {
      "id": "notice-3",
      "datetime": "2025-08-01T09:00:00",
      "title": "お笑いライブ出演芸人の情報を公開いたしました",
      "summary": "第63回八王子祭のお笑いライブに出演いただく芸人の情報を公開いたしました。",
      "file": "Notice-3.html"
    }
  ]
}
```

#### STEP 3: 個別ページを作成

1. `Notice/Notice-1.html` をコピーして `Notice-4.html` を作成
2. 内容を新しいお知らせに合わせて編集
3. **重要**: `script/notice-validator.js` が自動で読み込まれるため、公開日時前はアクセスが制御されます

## 🛡️ セキュリティ機能

### 自動公開機能

- `datetime` で指定した日時になるまで、お知らせは表示されません
- 表示される日付は自動的に「YYYY年MM月DD日」形式にフォーマットされます

### アクセス制御機能

- 公開日時前のお知らせページに直接アクセスしようとすると：
  1. 「このお知らせはまだ公開されていません。」のアラートが表示
  2. 自動的にお知らせ一覧ページ（`Notice.html`）にリダイレクト
- これにより、URLを知っていても未公開コンテンツは閲覧できません

## 📝 個別ページ（Notice-X.html）の作成方法

### テンプレートをコピー

1. `Notice/Notice-1.html` をコピー
2. `Notice/Notice-X.html` にリネーム（Xは連番）

### 編集すべき箇所

#### 1. HTMLの head部分

```html
<meta name="description" content="新しいお知らせの説明">
<meta name="keywords" content="八王子祭, 学園祭, 工学院大学, 2025年, お知らせ, キーワード">
<title>新しいお知らせタイトル - 第63回八王子祭</title>
```

#### 2. メイン内容

```html
<h2 class="notice-title">新しいお知らせのタイトル</h2>
<p class="notice-date">2025年6月27日</p>

<div class="notice-text">
    <p>お知らせの本文内容...</p>
    
    <h3>詳細項目</h3>
    <ul>
        <li>項目1</li>
        <li>項目2</li>
    </ul>
</div>
```

### ⚠️ 注意事項

- **相対パスを変更しないこと**（`../`で始まるパス）
- **ファイル名は連番にすること**（Notice-1.html, Notice-2.html...）

## 🔍 システムの仕組み詳細

### 自動表示の流れ

1. ページ読み込み時に `script/notice-manager.js` が実行
2. `Notice/notices.json` からデータを取得
3. 日付順（新しい順）に自動ソート
4. 各ページに適切に表示

### 表示場所

- **ホームページ（index.html）**: 最新3件
- **お知らせ一覧（Notice.html）**: 全件表示

### エラー処理

- ファイル読み込み失敗時は適切なエラーメッセージを表示
- 読み込み中は「読み込み中...」を表示

## 🛠️ トラブルシューティング

### Q1: お知らせが表示されない

**原因:**

- `notices.json` の構文エラー
- ファイルパスの間違い

**解決方法:**

1. `notices.json` をJSONバリデーターでチェック
2. ファイル名・パスを再確認

### Q2: 新しいお知らせが一番上に表示されない

**原因:**

- `notices.json` で配列の順番が間違っている

**解決方法:**

- 新しいお知らせを配列の**先頭**に配置

### Q3: 個別ページでスタイルが崩れる

**原因:**

- 相対パス（`../`）の記述ミス

**解決方法:**

- `Notice-1.html` のパス記述を参考に修正

# 🚀 お知らせ追加 クイックガイド

## 📋 3分でできる！新しいお知らせの追加方法

**最終更新**: 2025年7月8日（自動公開・アクセス制御機能対応）

### STEP 1: notices.json を開く

`Notice/notices.json` をテキストエディタで開く

### STEP 2: 新しいお知らせデータを追加

配列の**先頭**に新しいデータを追加：

- **id**: notice-4, notice-5... （連番）
- **datetime**: `2025-08-15T10:00:00` （公開日時）
- **title**: お知らせのタイトル
- **summary**: 1-2行の概要文
- **file**: Notice-4.html... （IDと連番を合わせる）

### STEP 3: 個別ページ作成

1. `Notice/Notice-1.html` をコピー
2. `Notice/Notice-X.html` にリネーム
3. 内容を編集

---

## 🔧 notices.json 編集例

**新しいお知らせを追加する場合:**

```json
{
  "notices": [
    {
      "id": "notice-4",
      "datetime": "2025-08-15T10:00:00", 
      "title": "新しいお知らせ",
      "summary": "概要文",
      "file": "Notice-4.html"
    },
    {
      "id": "notice-3",
      "datetime": "2025-08-01T09:00:00",
      "title": "既存のお知らせ",
      "summary": "既存の概要",
      "file": "Notice-3.html"
    }
  ]
}
```

**⚠️ 重要: 新しいお知らせは配列の先頭（一番上）に追加！**

---

## 📅 datetime 形式について

公開日時は `YYYY-MM-DDTHH:MM:SS` で指定：

| 例 | 意味 |
|---|---|
| `2025-08-15T09:00:00` | 2025年8月15日 午前9時 |
| `2025-12-01T14:30:00` | 2025年12月1日 午後2時30分 |
| `2025-07-10T00:00:00` | 2025年7月10日 午前0時 |

---

## 🛡️ 自動機能

### 自動公開
- 指定した`datetime`まで、お知らせは非表示
- 日時が来ると自動的に表示開始

### アクセス制御
- 公開前のページに直接アクセス → 自動でお知らせ一覧にリダイレクト
- 「まだ公開されていません」アラート表示

---

## ✅ 確認ポイント

### 追加後は必ずチェック

- [ ] 指定日時になったら表示されているか
- [ ] お知らせ一覧で表示されているか  
- [ ] 個別ページへのリンクが動作するか
- [ ] 公開前は直接アクセスできないか

### よくあるミス

- ❌ JSONの構文エラー（カンマ忘れなど）
- ❌ datetime形式の間違い
- ❌ 配列の順番間違い（新しいものが下にある）
- ❌ ファイル名の不一致

---

## 🆘 困った時は

3. **ブラウザ**でエラーがないか確認（F12キー）

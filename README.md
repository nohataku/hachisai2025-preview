# 第63回八王子祭 公式ホームページ

## 📝 プロジェクト概要

工学院大学学園祭実行委員会八王子祭実行部が運営する、第63回八王子祭の公式ホームページです。

- **開催日**: 2025年9月6日（土）・7日（日）
- **テーマ**: 「宇宙旅行」
- **会場**: 工学院大学八王子キャンパス

## 🚀 お知らせ管理システム

### 新機能

このホームページには、お知らせを効率的に管理できる自動更新システムが導入されています。

### 📋 運営メンバー向けガイド

お知らせの追加・更新方法については、以下のドキュメントをご確認ください：

- **📖 [詳細ガイド](お知らせ管理システム_運営ガイド.md)** - システムの詳細説明
- **⚡ [クイックガイド](お知らせ追加_クイックガイド.md)** - 3分でできる追加方法

### 🛠️ 管理ツール

- **管理ツール**: `Notice/notice-manager-tool.html`
- **データファイル**: `Notice/notices.json`

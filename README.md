# 第63回八王子祭 公式ホームページ

## 📝 プロジェクト概要

工学院大学学園祭実行委員会八王子祭実行部が運営する、第63回八王子祭の公式ホームページです。

- **開催日**: 2025年9月6日（土）・7日（日）
- **テーマ**: 「宇宙旅行」
- **会場**: 工学院大学八王子キャンパス

## 🚀 お知らせ管理システム

### 最新機能 (2025年7月8日更新)

このホームページには、以下の機能を持つ高度なお知らせ管理システムが導入されています：

- **📅 自動公開機能**: 指定した日時に自動でお知らせを公開
- **🛡️ アクセス制御**: 公開前のお知らせへの直接アクセスを防止
- **⏰ 日時指定**: 年月日だけでなく時刻まで詳細に指定可能
- **🔄 自動更新**: JSONファイルの更新だけで全ページに反映

### 📋 運営メンバー向けガイド

お知らせの追加・更新方法については、以下のドキュメントをご確認ください：

- **📖 [詳細ガイド](お知らせ管理システム_運営ガイド.md)** - システムの詳細説明
- **⚡ [クイックガイド](お知らせ追加_クイックガイド.md)** - 3分でできる追加方法

### 🛠️ 管理ツール

- **データファイル**: `Notice/notices.json` - お知らせデータ（日時指定対応）
- **自動読み込み**: `script/notice-manager.js` - 公開日時チェック機能
- **アクセス制御**: `script/notice-validator.js` - 未公開コンテンツ保護
